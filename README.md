# Riverside Clinic Cybersecurity Improvement Plan

## Overview

This project applies the NIST Cybersecurity Framework (CSF) 2.0 to a fictional small outpatient healthcare clinic called Riverside Family Clinic.

The goal of the project was to:
- create a Current Profile and Target Profile,
- identify cybersecurity gaps,
- and develop a realistic improvement plan appropriate for a small healthcare provider.

The assessment focused on:
- ransomware resilience,
- patient data protection,
- vendor dependency,
- operational continuity,
- and incident response readiness.

---

## Frameworks Used

- NIST Cybersecurity Framework (CSF) 2.0
- NIST SP 1300 Small Business Quick-Start Guide
- NIST SP 1301 Organizational Profiles

---

## Key Risks Identified

- Ransomware
- Phishing
- Weak MFA coverage
- Lack of tested restoration procedures
- Vendor dependency
- Incomplete incident response planning
