# Current Profile

The current cybersecurity posture reflects a small clinic with limited internal cybersecurity capabilities and strong dependence on third-party IT support.

## Key Findings

| Area | Current State |
|---|---|
| Cybersecurity roles and responsibilities | No internal cybersecurity staff; responsibility falls on clinic owner and manager |
| Legal, regulatory and contractual cybersecurity requirements | Staff receive privacy awareness training, but legal and vendor security requirements are not documented |
| Asset inventory | Informal inventory exists |
| Data classification | Sensitive data is stored, but formal classification do not exist |
| Key cybersecurity threats documentation | No written threat documentation |
| Third-party risk | Clinic relies heavily on third-party vendors |
| MFA | Enabled for email but not billing |
| Patching and updating | Systems updated periodically, but patch status reporting and tracking are informal|
| Backups | Backups performed but restoration not tested |
| Full-disk encryption | Staff use clinic-owned laptops/desktops but not all are encrypted |
| Common indicators of cybersecurity incident | General cybersecurity awareness training received, but reporting procedures are informal |
| External monitoring | Basic monitoring performed, but scope and escalation procedures not formally documented |
| Incident response | No written incident response plan |
| Recovery playbook | No formal playbook |
