# Executive Summary

This project used the NIST Cybersecurity Framework (CSF) 2.0 Organizational Profile approach to evaluate the cybersecurity posture of Riverside Family Clinic, a fictional small outpatient healthcare provider.

The assessment compared the clinic’s Current Profile against a realistic 6–12 month Target Profile in order to identify operational and cybersecurity gaps.

## Highest-Priority Risks

- Ransomware
- Phishing
- Weak MFA coverage
- Lack of tested restoration procedures
- Vendor dependency
- Incomplete incident response planning

## Recommended Improvements

- Expand MFA coverage
- Formalize backup restoration testing
- Create incident response procedures
- Improve vendor responsibility documentation
- Maintain asset inventory
- Improve staff reporting procedures

## Conclusion

The proposed improvements are intended to strengthen patient data protection, reduce operational disruption, and improve ransomware resilience while remaining achievable within the clinic’s staffing and budget limitations.
